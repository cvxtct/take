# Triage labels

Use these default labels when helpful; every small change need not go through
all states. Labels describe readiness, not permission to merge or publish.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs evaluation |
| `needs-info` | `needs-info` | Needs clarification |
| `ready-for-agent` | `ready-for-agent` | Clear enough for AI implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be pursued |

When a skill refers to a triage role, use the corresponding GitHub label.
